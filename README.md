### Задание 2
Проведите сканирование Metasploitable в режимах SYN, FIN, Xmas, UDP.

Запишите сеансы сканирования в Wireshark.

Ответьте на следующие вопросы:

- Чем отличаются эти режимы сканирования с точки зрения сетевого трафика?
- Как отвечает сервер?

Приведите ответ в свободной форме.

### Решение 2 

Отличия режимов сканирования:

- SYN: Использует стандартный TCP handshake без завершения, быстрое и надежное

- FIN: Отправляет FIN-пакеты как при нормальном закрытии соединения, стелс-метод

- Xmas: Использует редко применяемую комбинацию флагов FIN/PSH/URG, максимально скрытное

- UDP: Работает с протоколом без установления соединения, медленное из-за таймаутов

Ответ сервера:

- SYN: Открытые порты → SYN-ACK, закрытые → RST-ACK

- FIN/Xmas: Открытые порты → игнорируют, закрытые → RST

- UDP: Открытые порты → редко отвечают, закрытые → ICMP Port Unreachable
